Please make sure you're already install **Node.js v.23** or higher to use following **npm** command and **MySQL Database** in your machine.

## Run Locally

Clone the project

```bash
  git clone https://github.com/lkswilliam2009/backend-penjualan.git
```

Go to the project directory

```bash
  cd backend-penjualan
```

Install dependencies

```bash
  cd tech-test-backend-node/src
```

```bash
  npm install 
```

Start the server

```bash
  npx tsx server.ts
```
